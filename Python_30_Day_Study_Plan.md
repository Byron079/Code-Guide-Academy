# 30-Day Python Study Plan

A realistic, day-by-day path from zero to job-ready fundamentals — roughly 1–2 hours per day. Each day pairs a small dose of theory with hands-on practice. Adjust the pace to fit your schedule; consistency matters more than speed.

**How to use this plan:** each day references topics from your Python Study Guide, Cheat Sheet, Project Examples, and Code Samples files. Do the reading, type out the examples yourself (don't copy-paste), then complete the day's task before moving on.

## Daily Habits Worth Building

- **Type, don't copy.** Typing code (even code you've seen before) builds muscle memory that copy-pasting never does.
- **Break something on purpose.** Once a script works, deliberately introduce a bug and practise reading the error message and fixing it.
- **Explain it out loud.** If you can't explain what a piece of code does in plain English, you don't fully understand it yet — go back to the theory.
- **Keep a "bugs I've fixed" log.** Write one line per day about a mistake you made and how you solved it. This becomes a powerful personal reference.

## If You Fall Behind

This plan assumes roughly 1–2 hours a day, 7 days a week. If you can only manage a few days a week, simply stretch it into a 6–8 week plan instead — do not skip days' content to "catch up" on the calendar. Understanding each topic matters far more than finishing on Day 30 exactly.

## After Day 30

- Revisit the two projects you found hardest and rebuild them from scratch without referencing your old code.
- Pick a specialisation (web development, data analysis, automation, or general software engineering) and go deeper into its core library (Flask/Django, pandas/NumPy, or scripting + APIs).
- Start contributing small fixes to an open-source project on GitHub to get comfortable with real-world codebases.
